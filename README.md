# TaskFlow Mini

A simple and elegant task management application built to help users organize daily activities, manage deadlines, and stay productive.

## Overview

TaskFlow Mini is a frontend web application that allows users to create, organize, track, and manage their daily tasks through a clean and intuitive interface.

It features task categorization, priority levels, deadline tracking, productivity statistics, and a personalized dashboard.

## Features

- **Task Management:** Create, edit, delete, and complete tasks.
- **Task Categories:** Organize tasks into Personal, Work, School, Shopping, and Other.
- **Priority Levels:** Assign Low, Medium, or High priority.
- **Deadline Tracking:** Set due dates and identify overdue tasks.
- **Search and Filters:** Search, filter, and sort tasks.
- **Productivity Dashboard:** Track total, completed, pending, and overdue tasks.
- **Category Breakdown:** View tasks grouped by category.
- **Task Reminders:** Receive browser notifications for reminders.
- **Personalization:** Save your name and customize your welcome experience.
- **Local Storage:** Keep tasks and preferences saved in your browser.
- **Responsive Design:** Use the application across different screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage API
- Browser Notifications API

## Getting Started

### Run Locally

1. Clone the repository:

   ```bash
git clone https://github.com/favourcottrell-cloud/taskflow-mini.git
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` in your browser, or use the Live Server extension.

4. Start creating and managing your tasks.
